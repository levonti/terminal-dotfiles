# Сочетания клавиш Kitty

`super` в общем конфиге соответствует `Command` на macOS и клавише `Super` на Linux. Сочетания одинаковы в конфиге; GNOME и KDE могут захватывать часть из них как системные.

| Действие | macOS | Linux |
| --- | --- | --- |
| Новая вкладка | `Command+T` | `Super+T` |
| Новое окно приложения | `Command+N` | `Super+N` |
| Закрыть вкладку | `Command+W` | `Super+W` |
| Новая панель внутри вкладки | `Command+Enter` | `Super+Enter` |
| Закрыть панель | `Command+Shift+D` | `Super+Shift+D` |
| Следующая / предыдущая вкладка | `Command+Right/Left` | `Super+Right/Left` |
| Копировать / вставить | `Command+C/V` | `Super+C/V` |
| Автокопирование в системный буфер | Выделить текст мышью | Выделить текст мышью |
| Открыть ссылку | `Command` + левый клик | `Super` + левый клик |
| Поиск в прокрутке | `Command+F` | `Super+F` |
| Открыть `kitty.conf` | `Command+,` | `Super+,` |

На Mac `Fn+Up/Down` прокручивают вывод, а `Fn+Left/Right` отправляют Home/End в приложение: Bash и zsh переходят к началу/концу текущей строки. Отдельные сочетания для перехода к вкладке по номеру и постоянная нумерация панелей пока не добавлены.

## Выделение и ссылки

Выделение мышью автоматически заменяет системный буфер обмена на Mac и Linux. В tmux, редакторе или другой программе, захватившей мышь, удерживайте `Shift` при выделении. Kitty обрабатывает эти действия на клиенте, поэтому они работают и в SSH-сеансах.

`Command/Super` + клик открывает ссылку, даже если программа захватила мышь или в терминале осталось выделение. При наведении на гиперссылку Kitty показывает её адрес. Веб-ссылка открывается в браузере по умолчанию на устройстве с Kitty. Если GNOME или KDE перехватывает `Super` + клик как системный жест, переназначьте этот жест в настройках оконной системы, чтобы сочетание доходило до Kitty.
