# Сочетания клавиш Kitty

`super` в общем конфиге соответствует `Command` на macOS и клавише `Super` на Linux. Сочетания одинаковы в конфиге; GNOME и KDE могут захватывать часть из них как системные.

| Действие | macOS | Linux |
| --- | --- | --- |
| Новая вкладка | `Command+T` | `Super+T` |
| Новое окно приложения | `Command+N` | `Super+N` |
| Закрыть вкладку | `Command+W` | `Super+W` |
| Новая панель внутри вкладки | `Command+Enter` | `Super+Enter` |
| Закрыть панель | `Command+Shift+D` | `Super+Shift+D` |
| Следующая / предыдущая вкладка | `Command+Right/Left` | `Super+Right/Left` |
| Вкладка по номеру 1–9 | `Command+1…9` | `Super+1…9` |
| Выбрать вкладку из списка | `Command+P` | `Super+P` |
| Переименовать вкладку | `Command+Shift+T` | `Super+Shift+T` |
| Копировать / вставить | `Command+C/V` | `Super+C/V` |
| Автокопирование в системный буфер | Выделить текст мышью | Выделить текст мышью |
| Открыть ссылку | `Command` + левый клик | `Super` + левый клик |
| Поиск в прокрутке | `Command+F` | `Super+F` |
| Открыть `kitty.conf` | `Command+,` | `Super+,` |

На Mac `Fn+Up/Down` прокручивают вывод, а `Fn+Left/Right` отправляют Home/End в приложение: Bash и zsh переходят к началу/концу текущей строки. Постоянная нумерация панелей внутри вкладки пока не добавлена. Пустое имя при переименовании возвращает автоматический заголовок; правила подписей описаны в [настройках вкладок](kitty-tabs.md).

## Переход по словам в оболочке

В общих Bash и Zsh `Option+Left/Right` на macOS и `Alt+Left/Right` на Linux перемещают курсор по словам: влево — к началу предыдущего слова, вправо — к концу следующего. Привязки добавлены в Emacs- и Vi-режимы редактирования строки. Zsh использует `emacs-backward-word` / `emacs-forward-word`, чтобы переход вправо завершался на конце слова, как в Readline Bash. Границы слов с пунктуацией сохраняют правила каждой оболочки: в Zsh они зависят от `WORDCHARS`.

Это настройки оболочки на принимающем устройстве. При SSH обновите общий конфиг Bash/Zsh на конечном хосте и откройте новое подключение. В уже открытом Zsh можно выполнить `source ~/.zshrc`, в Bash — `source ~/.bashrc`. Если принимающее устройство использует отдельную копию конфигов, обновление Git на клиенте эту копию не изменит.

Kitty передаёт исходные коды `ESC [1;3D` / `ESC [1;3C`; глобальное переназначение для редакторов или MC не добавляется. Если вместо движения появляются символы `;3D` / `;3C`, проверьте загрузку обновлённого конфига оболочки. Для начала и конца строки по-прежнему используются `Fn+Left/Right` на Mac или `Home/End`.

[Движение по словам в Zsh](https://zsh.sourceforge.io/Doc/Release/Zsh-Line-Editor.html#Movement), [команды Readline в Bash](https://www.gnu.org/software/bash/manual/html_node/Readline-Movement-Commands.html).

## Выделение и ссылки

Выделение мышью автоматически заменяет системный буфер обмена на Mac и Linux. В tmux, редакторе или другой программе, захватившей мышь, удерживайте `Shift` при выделении. Kitty обрабатывает эти действия на клиенте, поэтому они работают и в SSH-сеансах.

`Command/Super` + клик открывает ссылку, даже если программа захватила мышь или в терминале осталось выделение. При наведении на гиперссылку Kitty показывает её адрес. Веб-ссылка открывается в браузере по умолчанию на устройстве с Kitty. Если GNOME или KDE перехватывает `Super` + клик как системный жест, переназначьте этот жест в настройках оконной системы, чтобы сочетание доходило до Kitty.
