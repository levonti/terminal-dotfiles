# Вкладки Kitty

Общий конфиг использует встроенный стиль `fade` с `tab_fade 1`: одна ячейка по краям полностью совпадает с фоном панели. Получаются плоские вкладки с зазором, без градиента и вертикальных разделителей. Активная вкладка выделена бирюзовым фоном и жирным текстом; остальные сохраняют светлый текст на тёмном фоне.

Номер перед названием различает одинаковые вкладки. Для заголовка `~` отображается `local`, для абсолютного пути или пути с `~/` — имя последнего каталога. Корневой путь сохраняется как есть.

Неактивный SSH-заголовок `user@host: ~/some/project` сокращается до `host:project`, а командный `host: tmux new -s work` — до `host:tmux`. Префикс `root@host` сохраняется целиком. Это сокращение текста заголовка, а не определение сетевого подключения: нестандартные и вручную заданные заголовки с `: ` могут также сокращаться. Активная вкладка сохраняет более подробный заголовок. Длинные подписи ограничены 28 ячейками; заголовок самого окна не меняется.

Шаблоны используют встроенные выражения Kitty без отдельного Python-обработчика. Проверен вид восьми вкладок в Kitty 0.49.0 на macOS. При меньшей ширине окна или большем числе вкладок подписи всё равно могут обрезаться. Контраст заданных цветов текста и фона: 8.61:1 для активной вкладки и 7.88:1 для неактивной.

Для альтернативного стиля добавьте в `~/.config/kitty/kitty.local.conf`:

```conf
# Закруглённый Powerline
tab_bar_style powerline
tab_powerline_style round
```

Или для тонких разделителей:

```conf
tab_bar_style separator
tab_separator " │ "
```

Мягкий fade с несколькими ячейками по краям также возможен:

```conf
tab_bar_style fade
tab_fade 0.15 0.35 0.7 1
```

Удалите эти строки, чтобы вернуться к общему стилю. Перезагрузите настройки сочетанием `Ctrl+Command+,` на macOS или `Ctrl+Shift+F5` на Linux; SSH-сессии продолжаются.
