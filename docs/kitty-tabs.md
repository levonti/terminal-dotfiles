# Вкладки Kitty

Общий конфиг использует встроенный стиль `fade` с `tab_fade 1`: одна ячейка по краям полностью совпадает с фоном панели. Получаются плоские вкладки с зазором, без градиента и вертикальных разделителей. Активная вкладка выделена бирюзовым фоном и жирным текстом; остальные сохраняют светлый текст на тёмном фоне.

Номер перед названием соответствует переходу по `Command+1…9` на macOS или `Super+1…9` на Linux. `Command/Super+P` открывает список вкладок. Для абсолютного пути или пути с `~/` показывается имя последнего каталога; домашний и корневой пути сохраняются как `~` и `/`.

SSH-заголовок `user@host: ~/some/project` сокращается до `host:project`, а командный `host: tmux new -s work` — до `host:tmux`. Префикс `root@host` сохраняется вместе с каталогом. Активная и неактивная вкладки используют одну подпись. Это обработка текста заголовка, а не определение подключения: нестандартный автоматический заголовок с `: ` может также сокращаться. Длинные подписи ограничены 28 ячейками; заголовок самого окна не меняется.

Если две оболочки открыты в одном каталоге, задайте им имена по назначению через `Command/Super+Shift+T`, например `infra` и `deploy`. Назначенное имя сохраняется при смене каталога и имеет приоритет над автоматическим заголовком и Kubie; двоеточия и пробелы в нём не сокращаются. Чтобы вернуть автоматическое название, откройте переименование и отправьте пустую строку. Общий конфиг не назначает имена пользовательским сессиям автоматически.

В сессии Kubie общий Bash/Zsh передаёт в Kitty выбранные контекст и namespace: например, `k8s:dev:example/app`. Значения читаются командами `kubie info ctx` и `kubie info ns` при появлении prompt, без обращения к API кластера. Подпись сохраняется во время выполнения команд. После `exit` во внешнюю оболочку метаданные очищаются. Это контекст сессии: параметры `--context`, `--kubeconfig` и `-n` отдельной команды его не меняют. Для работающих оболочек перечитайте соответствующий `.zshrc` / `.bashrc` или откройте новую вкладку; уже открытая сессия Kubie также должна загрузить обновлённый конфиг.

Общая функция `draw_title` в `tab_bar.py` используется как стилем `fade`, так и сетевой панелью `custom`. Оба файла должны быть установлены через Stow. В `custom` распределение ширины не зависит от активной вкладки: её переключение меняет цвет и жирность без перемещения соседних вкладок. При недостатке места подписи сокращаются равномерно, с сохранением приоритета `root@`; сетевой блок уступает место вкладкам. Контраст заданных цветов текста и фона: 8.61:1 для активной вкладки и 7.88:1 для неактивной. Новое поведение проверяется автоматически; прежняя визуальная проверка Kitty 0.49.0 не подтверждает новый вид на всех устройствах.

Для альтернативного стиля добавьте в `~/.config/kitty/kitty.local.conf`:

```conf
# Закруглённый Powerline
tab_bar_style powerline
tab_powerline_style round
```

Или для тонких разделителей:

```conf
tab_bar_style separator
tab_separator " │ "
```

Мягкий fade с несколькими ячейками по краям также возможен:

```conf
tab_bar_style fade
tab_fade 0.15 0.35 0.7 1
```

Удалите эти строки, чтобы вернуться к общему стилю. Перезагрузите настройки сочетанием `Ctrl+Command+,` на macOS или `Ctrl+Shift+F5` на Linux; SSH-сессии продолжаются.
