# Вкладки Kitty

Общий конфиг использует встроенный стиль `fade` с `tab_fade 1`: одна ячейка по краям полностью совпадает с фоном панели. Получаются плоские вкладки с зазором, без градиента и вертикальных разделителей. Активная вкладка выделена бирюзовым фоном и жирным текстом; остальные сохраняют светлый текст на тёмном фоне.

Номер перед названием соответствует переходу по `Command+1…9` на macOS или `Super+1…9` на Linux. `Command/Super+P` открывает список вкладок. Для абсолютного пути или пути с `~/` показывается имя последнего каталога; домашний и корневой пути сохраняются как `~` и `/`.

Локальная вкладка показывает каталог: например, `project`. При запуске программы он сохраняется: `project · htop`. Показывается имя исполняемого файла, без аргументов команды. SSH-вкладка сохраняет хост и последний сообщённый удалённый каталог: `host:project · htop`; после завершения команды возвращается `host:project`. Префикс `root@host` сохраняется. Активная и неактивная вкладки используют одну подпись. Длинные подписи ограничены 40 ячейками; в стиле `custom` при сокращении сохраняется место для имени команды, если вкладке доступно хотя бы 12 ячеек текста. В более тесной панели используйте список вкладок. Автоматическая подпись вкладки не меняет заголовок самого окна.

Если две оболочки открыты в одном каталоге, задайте им имена по назначению через `Command/Super+Shift+T`, например `infra` и `deploy`. Назначенное имя сохраняется при смене каталога и имеет приоритет над автоматическим заголовком и Kubie; двоеточия и пробелы в нём не сокращаются. Чтобы вернуть автоматическое название, откройте переименование и отправьте пустую строку. Общий конфиг не назначает имена пользовательским сессиям автоматически.

В локальной сессии Kubie общий Bash/Zsh получает текст через `starship module kubernetes`: это тот же модуль и конфиг, что используются в prompt, включая `STARSHIP_CONFIG`. Примеры: `[☸ DEV example::app]`, `[☸ ! PROD example::app]`, `[☸ ? ENV default::app]`. ANSI-оформление удаляется; цвета и жирность задаёт состояние вкладки. Каталог и команда дополняют контекст: `[☸ DEV example::app] project · htop`. Starship читает локальный kubeconfig без обращения к API кластера. Если Starship или его Kubernetes-модуль отключён, отдельный формат для вкладки не придумывается.

Метаданные привязаны к PID передавшей их оболочки и принимаются только при `KUBIE_ACTIVE` у локального процесса переднего плана. После выхода PID перестаёт существовать, и контекст скрывается даже при возврате в старую оболочку без новых hooks. Обычный prompt также очищает метаданные. При переходе в SSH локальный контекст не подставляется вместо удалённого заголовка. Это контекст сессии: параметры `--context`, `--kubeconfig` и `-n` отдельной команды его не меняют. Для работающих оболочек перечитайте соответствующий `.zshrc` / `.bashrc` или откройте новую вкладку; уже открытая сессия Kubie также должна загрузить обновлённый конфиг.

Обычный SSH не сообщает клиенту о выполнении команд автоматически. Общие Bash/Zsh-конфиги на удалённом сервере добавляют сообщения о каталоге и запуске команды через OSC 2, когда заданы `SSH_TTY` или `SSH_CONNECTION` и используется совместимый терминал. Для Zsh используется `preexec`, для Bash 4.4+ — `PS0`; существующий `DEBUG` trap сохраняется. В Bash 3.2 собственный hook сообщает только каталог. Если сервер не отправляет обновления заголовка, клиент не может определить запущенную на нём программу; обновите удалённый конфиг оболочки. Переданный ранее удалённый каталог сохраняется, когда TUI заменяет заголовок своим именем; при наличии подходящего OSC 7 путь берётся из него. Локальный каталог SSH-клиента вместо удалённого не показывается.

Общая функция `draw_title` в `tab_bar.py` используется как стилем `fade`, так и сетевой панелью `custom`. Оба файла должны быть установлены через Stow. В `custom` распределение ширины не зависит от активной вкладки: её переключение меняет цвет и жирность без перемещения соседних вкладок. При недостатке места подписи сокращаются равномерно, с сохранением приоритета `root@`; сетевой блок уступает место вкладкам. Контраст заданных цветов текста и фона: 8.61:1 для активной вкладки и 7.88:1 для неактивной. Новое поведение проверяется автоматически; прежняя визуальная проверка Kitty 0.49.0 не подтверждает новый вид на всех устройствах.

Для альтернативного стиля добавьте в `~/.config/kitty/kitty.local.conf`:

```conf
# Закруглённый Powerline
tab_bar_style powerline
tab_powerline_style round
```

Или для тонких разделителей:

```conf
tab_bar_style separator
tab_separator " │ "
```

Мягкий fade с несколькими ячейками по краям также возможен:

```conf
tab_bar_style fade
tab_fade 0.15 0.35 0.7 1
```

Удалите эти строки, чтобы вернуться к общему стилю. Перезагрузите настройки сочетанием `Ctrl+Command+,` на macOS или `Ctrl+Shift+F5` на Linux; SSH-сессии продолжаются.
