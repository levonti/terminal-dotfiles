# Сетевые графики в Kitty

В верхней панели справа отображается сеть компьютера, на котором запущен Kitty: Mac или Linux. Это суммарный трафик физических интерфейсов (Wi-Fi / Ethernet), включая SSH, браузер и фоновые приложения. Подключение по SSH не переключает источник на удалённый компьютер. Подпись `Mac` / `Linux` обозначает источник измерений.

Входящий трафик (`↓`) выделен зелёным, исходящий (`↑`) — голубым. Мини-графики показывают последние 60 секунд, время идёт слева направо. Каждый график занимает 8 столбцов по 7.5 секунды. Каждый столбец сохраняет максимальную измеренную скорость своего интервала, чтобы короткий всплеск оставался заметен. Цифры рядом — скорость за последний интервал измерения около одной секунды.

Все скорости указаны в битах в секунду: `k` — килобиты, `M` — мегабиты, `G` — гигабиты. Например, `1.2Mb/s` соответствует 1.2 Мбит/с, примерно 150 кБ/с. Отдельная подпись длительности и шкалы справа убрана. Общая шкала RX/TX сохраняется: она округляется вверх к значениям 1/2/5 и учитывает пики последней минуты; минимальная граница — 100 кбит/с. Высота показывает относительную активность в пределах этой минуты; абсолютные значения читаются по текущим скоростям. Это фактический трафик, а не результат измерения пропускной способности интернет-канала.

`·` — ещё нет измерений, `▁` — измеренная нулевая или небольшая активность, `--` — сбор начался и нужны два отсчёта. Ошибка чтения показывается как `network unavailable`, а не как нулевой трафик. После сна или сброса счётчиков выполняется новая привязка без искусственного пика.

Счётчики читаются раз в секунду без запуска внешних программ и без root. На macOS используется публичный `sysctl` (`IFMIB_IFALLDATA / IFDATA_GENERAL`) с полными 64-битными счётчиками интерфейсов `en*`. На Linux используются счётчики `/proc/net/dev`; физические и гостевые аппаратные интерфейсы выбираются по наличию `/sys/class/net/<имя>/device`. Если аппаратных интерфейсов нет, например в контейнере, выбирается один интерфейс маршрута по умолчанию с наименьшей метрикой: IPv4, затем IPv6.

Виртуальные мосты, loopback и VPN-интерфейсы не суммируются с физическими: VPN-трафик уже учитывается на физическом интерфейсе. AirDrop по отдельным интерфейсам `awdl*`, трафик только внутри VM и loopback в эти графики не входят. В контейнере источник ограничен его сетевым пространством; это не статистика всего Linux-хоста.

Активные и неактивные вкладки сохраняют имя хоста и краткий каталог либо команду. Префикс `root@` получает приоритет при распределении ширины. Ширины не зависят от фокуса. Правая зона сети исключена из областей клика по вкладкам.

Сначала резервируется место для подписей вкладок, затем выбирается сетевой режим по оставшимся ячейкам:

| Режим | macOS | Linux | Содержимое |
| --- | --- | --- | --- |
| Полный | 43 | 45 | Источник, два графика, текущие скорости с единицами |
| Компактный | 25 | 27 | Источник и текущие скорости с единицами |
| Скрытый | 0 | 0 | Всё место остаётся вкладкам |

Между вкладками и видимой сетью остаётся одна свободная ячейка. При дефиците места сеть скрывается до сокращения подписей. Переход через ширину 120 ячеек сам по себе больше не меняет режим. Если даже без сети вкладки не помещаются, подписи сокращаются; в очень узком окне используйте `Command/Super+P`. Для вертикальной панели или неподдерживаемой ОС используется обычный стиль `fade` без сети. Переключение на встроенный стиль `fade` также возвращает стандартное распределение ширины Kitty.

## Подключение и отключение

Общий конфиг Kitty сохраняет стиль `fade`. Для сетевой панели нужен `tab_bar.py` рядом с установленным `kitty.conf`. Если пакет Kitty был подключён до появления этого файла, из корня репозитория повторите установку ссылок.

```sh
stow --no-folding --simulate --verbose --target="$HOME" kitty
stow --no-folding --target="$HOME" kitty
```

Добавьте следующие строки в `~/.config/kitty/kitty.local.conf`. Остальные локальные настройки можно оставить в этом файле. [Пример локального конфига](../examples/kitty.local.conf.example).

```conf
tab_bar_style custom
tab_bar_min_tabs 1
```

Вторая строка нужна, если графики должны быть видны даже при одной вкладке. Чтобы вернуться к общему оформлению, удалите добавленные строки. Перечитайте настройки сочетанием `Ctrl+Command+,` на macOS или `Ctrl+Shift+F5` на Linux. После изменения самого `tab_bar.py` в Kitty 0.49.0 может понадобиться перечитать настройки дважды для сброса кэша. Перезагрузка настроек сохраняет вкладки и SSH-сессии. Сетевая история хранится в памяти процесса Kitty.

## Проверка

Проверяются расчёт бит/с, 64-битные счётчики, исключение виртуальных интерфейсов, выбор маршрута в Linux, сбросы, пробелы в истории, сохранение пиков, общая шкала, цвета и распределение ширины. Проверки подписей, трёх сетевых режимов, восьми вкладок при ширине 80/120/160 ячеек и метаданных Bash/Zsh находятся в `tests/test_kitty_tabs.py`; сетевые проверки — в `tests/test_network_bar.py`. Запускайте их из виртуального окружения, созданного `uv venv`: `python -m unittest discover -s tests -v`. Новые проверки выполнены на macOS; Linux aarch64 ранее проверялся для сбора счётчиков и прежнего формата панели. Новый графический вид и реальные сочетания клавиш требуют проверки в окне Kitty.
