# macOS

Текущий Mac уже использует Kitty, Starship, zoxide и обычный zsh без Oh My Zsh. Перед переключением на Git-ссылки сохраните копии действующих `~/.zshrc`, `~/.config/kitty/kitty.conf` и `~/.config/starship.toml`; их общие версии лежат в этом репозитории. `~/.zshrc.local` сохраните на месте: это личный файл, репозиторий его не заменяет.

Установите GNU Stow и зависимости shell, если их ещё нет:

```sh
brew install stow starship zoxide zsh-autosuggestions zsh-syntax-highlighting
```

Kitty на исходном Mac проверен в версии 0.49.0. Для других Mac используйте такой же выпуск; [официальный установщик](https://sw.kovidgoyal.net/kitty/binary/) позволяет выбрать версию. Общий конфиг использует шрифт `MesloLGS NF`; установите его на новом устройстве до проверки внешнего вида.

После подготовки резервных копий и освобождения трёх общих путей запустите Stow по инструкции в [README](../README.md#установка). Проверьте новый терминал, `z` и `zi`, подсказки и подсветку. Локальный `~/.zshrc.local` останется источником личных PATH и алиасов.
