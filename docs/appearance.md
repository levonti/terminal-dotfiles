# Внешний вид терминала

В Kitty используется MesloLGS NF 15 pt и тёмная палитра Nord. Последняя доработка затрагивает заголовок окна, вкладки, поля и Starship. Шрифт и основные ANSI-цвета сохраняются.

## Оценка всего окна

Субъективная оценка по скриншоту с восемью вкладками и проверке в Kitty 0.49.0 / Starship 1.26.0 на macOS: до доработки — 7/10, после — 8.5/10.

| Часть окна | До | После | Причина и изменение |
| --- | --- | --- | --- |
| Заголовок macOS | 6.5 | 8.5 | Тёплый системный серый заменён на цвет шапки терминала |
| Вкладки при восьми сессиях | 6.5 | 8.5 | Длинные подписи теснились; сокращены каталоги и команды, между вкладками появился зазор |
| Шрифт | 8 | 8 | Читаемый моноширинный шрифт и размер сохранены |
| Цвета и контраст | 8 | 8.5 | Каталог выделен бирюзовым, shell стал спокойнее, Git-статус — жёлтым |
| Prompt и Git | 6 | 8.5 | Убраны `on` и лишний префикс пути у корня репозитория; добавлены счётчики |
| Отступы и ритм | 6.5 | 8.5 | Поля увеличены с 6 до 12 pt; группы команд разделены пустой строкой |

Это экспертная визуальная оценка, а не автоматическая метрика и не полная проверка доступности. Очень узкие окна и десятки вкладок всё равно потребуют сокращения названий. Linux и полноэкранные TUI при этих изменениях не проверялись.

## Приглашение Starship

Две строки отделяют контекст от ввода команды. Имя shell сохраняется спокойным серым цветом; каталог — главный бирюзовый акцент. Имя хоста появляется при SSH. Краткие Git-обозначения:

| Обозначение | Значение |
| --- | --- |
| `~N` | N изменённых файлов |
| `?N` | N неотслеживаемых файлов |
| `+N` | N файлов в индексе |
| `↑N` / `↓N` | N коммитов впереди / позади отслеживаемой ветки |
| `conflict:N` | N конфликтов; выделяются красным |
| `exit:N` справа | Ненулевой код завершения команды |

Повтор prompt после пустого Enter — нормальное поведение shell. Подчёркивание существующего пути при вводе команды выполняет плагин подсветки; оно сохранено.

Чистый репозиторий не показывает нулевые счётчики. Без отслеживаемой ветки индикатор ahead/behind отсутствует. Изменения файла Starship вступают в силу при следующей отрисовке prompt; старый вывод остаётся в истории терминала.

## Сравнение вариантов

1. **Двухстрочное приглашение, вкладки с зазором: 8.5/10.** Выбранный вариант: контекст хорошо читается, а команда начинается с новой строки.
2. **Однострочное приглашение: 8/10.** Экономит высоту, но оставляет меньше места для длинных команд. Для локального варианта скопируйте Starship TOML в отдельный файл, удалите `$line_break` из `format` и задайте `STARSHIP_CONFIG` в `~/.zshrc.local`.
3. **Прежний вид с разделителями и плотным prompt: 7/10.** Сохранял больше подробностей в названиях вкладок, но в восьми вкладках многие из них превращались в многоточия.

Для сравнения использовалось отдельное окно Kitty с восемью тестовыми вкладками и настоящим временным Git-репозиторием. Проверены изменённые и неотслеживаемые файлы, локальный коммит впереди upstream, ошибка команды и время выполнения. Это тестовые данные, а не изменения в пользовательском проекте.
