# Локальные переопределения

Публичный репозиторий содержит общие настройки. Личные пути и настройки конкретного устройства живут в файлах домашнего каталога, которые не являются ссылками на публичный репозиторий.

| Файл | Когда загружается | Для чего использовать |
| --- | --- | --- |
| `~/.zshrc.local` | В начале `.zshrc` | `PATH`, переменные окружения, личные алиасы; `STARSHIP_CONFIG` должен быть задан здесь до инициализации Starship |
| `~/.zshrc.local.post` | После общих настроек, перед подсветкой синтаксиса | Переопределение алиасов, функций и клавиш zsh |
| `~/.config/kitty/kitty.local.conf` | В конце `kitty.conf` | Настройки терминала для конкретного устройства |
| `~/.config/starship.local.toml` | Только если задан `STARSHIP_CONFIG` | Полная локальная замена общего `starship.toml` |

Kitty поддерживает `globinclude`, поэтому локальный файл необязателен: [документация Kitty](https://sw.kovidgoyal.net/kitty/conf/). Starship использует один конфигурационный TOML-файл и позволяет выбрать его через `STARSHIP_CONFIG`: [документация Starship](https://starship.rs/config/). Частичного слияния общего и локального TOML здесь нет.

Для одинакового внешнего вида оставляйте цветовую схему, шрифт и prompt в общем слое. В локальных файлах удобно хранить личные пути, алиасы и исключения для клавиш, которые захватывает рабочая среда.

Если потребуется синхронизировать личные алиасы и пути между устройствами, используйте отдельный закрытый репозиторий `terminal-dotfiles-private`. Файлы с секретами и ключами храните в предназначенном для них хранилище. Публичный репозиторий работает и без закрытого.

GNU Stow следует запускать с `--no-folding`, чтобы каталог `~/.config/kitty` не стал ссылкой внутрь публичного репозитория. [Руководство Stow](https://www.gnu.org/software/stow/manual/stow.html).
